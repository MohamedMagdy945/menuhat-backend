# Actors

## Customer

The customer uses Menuhat to:

- Discover restaurants
- Browse restaurant menus
- Place orders
- Track orders
- Review restaurants

## Restaurant Owner

The restaurant owner uses Menuhat to:

- Register a restaurant
- Manage restaurant information
- Manage menus
- Manage menu items
- Manage orders

## Admin

The admin uses Menuhat to:

- Review restaurant registrations
- Approve or reject restaurants
- Manage restaurants
- Manage users
